## 🚀 Selected Projects

### 01 / [Token Show](https://github.com/shangxinxiaolin/Token-Show)

**让 AI 编程用量一目了然。**

本地优先的 Windows 桌面仪表盘，聚合多个 AI 编程客户端的 Token、模型和会话用量。支持中英双语与深浅主题，数据保留在本机。

`JavaScript` `Electron` `Chart.js` `Local-first`

[查看源码 →](https://github.com/shangxinxiaolin/Token-Show) · [下载体验 ↗](https://github.com/shangxinxiaolin/Token-Show/releases)

---

### 02 / [灵犀客服 · Lingxi](https://github.com/shangxinxiaolin/user-help)

**把 AI Agent 与真实业务流程连接起来。**

面向微服务架构的智能客服系统：Python 负责 Agent 与 RAG，Java 承载核心业务，通过 gRPC 协作。提供流式对话、操作确认与 Docker Compose 编排。

`Java` `Spring Boot` `Python` `FastAPI` `LangGraph` `gRPC` `Docker`

[查看源码 →](https://github.com/shangxinxiaolin/user-help) · [了解架构 ↗](https://github.com/shangxinxiaolin/user-help#架构图)

---

### 03 / [Redis MQ](https://github.com/shangxinxiaolin/redis-mq)

**从零理解消息如何被可靠地传递。**

基于 Go 与 Redis Streams 的轻量级消息队列学习项目，实践消费组、消息确认、失败重试与死信队列。

`Go` `Redis Streams` `Message Queue` `Learning Project`

[查看源码 →](https://github.com/shangxinxiaolin/redis-mq) · [阅读文档 ↗](https://github.com/shangxinxiaolin/redis-mq#-文档)
