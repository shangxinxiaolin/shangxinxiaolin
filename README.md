## Projects

### Local Merchant Review & Ordering Platform
**Tech Stack:** Spring Boot, Spring Security, JWT, PostgreSQL, Redis, Podman

- Designed and implemented RESTful backend services for a local merchant review and ordering platform, covering merchants, products, reviews, and user interactions
- Implemented stateless authentication and authorization using Spring Security with JWT, improving API scalability by eliminating server-side session storage
- Applied Redis caching (cache-aside pattern) to optimize read-heavy endpoints such as merchant listings and product details, reducing average response time by ~40% and significantly lowering database query volume under simulated load
- Designed and optimized relational database schemas and indexes to improve query performance for core business operations
- Conducted local load testing to compare performance before and after caching, validating latency improvements and system stability
- Containerized backend services using Podman to ensure consistent development and deployment environments

### Gym Membership & Reservation Service
**Tech Stack:** Go, Gin, PostgreSQL, Redis

- Developed backend services for gym membership management and class reservation workflows using Go and Gin
- Implemented RESTful APIs for member registration, class booking, reservation cancellation, and schedule queries
- Designed relational database schemas for members, trainers, class schedules, and reservations with a focus on clarity and extensibility
- Integrated Redis caching for frequently accessed class schedules and availability data, reducing average API response time by ~30% during local testing
- Designed reservation workflows with attention to data consistency and basic concurrency handling to prevent common double-booking scenarios
- Emphasized maintainable backend architecture with clear separation between routing, business logic, and data access layers
